How to interpret status

Recent contact means an accepted snapshot, a valid no-change response, or a validated event-stream response header within 90 seconds of sampling. It does not prove the authority is reachable now. Stale or failed contact never means a remote node is offline. A retained revision can continue serving during contact errors; store availability is shown separately. Timestamps are process-local observations and reset on restart.
