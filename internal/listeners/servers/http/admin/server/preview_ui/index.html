Import behavior and limits

Clicking Analyze export or Prepare records for review sends your selected bytes to this admin server. Selecting a file or typing does not upload it.

Analyze export retains source order, duplicate owners, comments and diagnostics. Prepare records for review is opt-in, requires an explicit ruleset ID and refuses the complete source if any row is ambiguous or unsupported.

Exports may contain private operational data. Source and results stay in page memory; credentials are never shared with the record editor. Protect the management transport.

Limits: 1 MiB input · 4,096 entries · 16 KiB tokens · 64 KiB logical commands. No apply, partial conversion, current-store comparison, export-completeness proof or full RouterOS policy conversion is offered.
